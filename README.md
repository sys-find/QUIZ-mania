# QUIZ-mania
QUIZ-mania: un divertimento che non va mai via!

## QUIZ-mania
Sito a scopo umoristico, senza nessuna intenzione di offendere nessuno.  
Il sito è ancora in fase di programmazione, quindi potrebbe presentare qualche piccolo bug  
(anche se ne dubito, dato che non c’è praticamente niente).

## IDEA DEL SITO
L’idea è di farlo diventare un sito di quiz con classifica mondiale.  
Ma non sarà un quiz normale, perché ci saranno domande un tantino… inaspettate!

Speriamo che il sito finale, quando uscirà, vi piacerà.  
Vi ringraziamo per il supporto.
